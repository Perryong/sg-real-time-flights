https://github.com/Perryong/3dstreet/blob/main/src/aframe-components/street-environment.js
https://assets.3dstreet.app/images/skies/2048-kloofendal_48d_partly_cloudy_puresky-sdr.jpeg

Used as a decorative sky in Cesium; it is not observed live weather. No 3DStreet application code is copied into this project.
